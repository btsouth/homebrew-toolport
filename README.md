# Toolport Homebrew tap

One local gateway for every MCP server, shared by every AI client. https://toolport.app

## Install

```sh
brew install --cask tsouth89/toolport/toolport
```

That taps this repo and installs the latest signed, notarized Toolport for your Mac
(Apple Silicon or Intel). Upgrade with `brew upgrade --cask toolport`.

The cask is generated from the main repo (`packaging/homebrew/toolport.rb` in
[tsouth89/toolport](https://github.com/tsouth89/toolport)).
